Release Notes
2.8
  • Multi-Tab Session Persistence: Fixed an issue where opening the extension popup on another browser tab during an active call could reset the transcription session or display a false caption warning, and preserved session completion status across tabs when closing a meeting tab.
  • Recent Meetings Actions & Layout: Added Generate Notes, Transcript download, and a delete (×) button for each entry in Recent Meetings with improved card spacing.
  • Streamlined Caption Warning Popup: Cleaned up the popup layout when live captions are turned off mid-call by swapping in the Enable Captions button in-place.
2.7
  • Active Call Detection & In-Page Prompt: Automatically detects active Microsoft Teams meetings to surface a one-click Capture Meeting Notes toast on the page, displays a clean empty state when no call is active, and alerts you with an Enable Captions button if live captions are turned off mid-call.
  • Notes File Naming Setting: Added an option in Settings to name AI summary files using either an AI-Generated Title (default) or the Teams Meeting Name.
  • Improved Teams Meeting Title Extraction: Reliably detects the Teams meeting title from the call header and tab title while ignoring unread notification counts and chat/navigation labels.
  • Streamlined File Naming Format: Standardized downloaded filenames to transcript_<meeting_name>_<monDD-YYYY>.txt and <title>_<monDD-YYYY>.md.
  • Recent Meetings & Reliability Improvements: Defaulted to the second-latest stable Gemini Flash model for higher endpoint availability, preserved failed sessions for retry even after closing the call tab, and added a Recent Meetings list in Settings to regenerate notes for the last 5 meetings.
  • UI Refinements: Updated header branding to mast for Teams, added an About section and Release Notes in Settings, and linked go/aistudio-apikey for API key setup instructions.
2.6
  • One-Click Capture: Unified caption enabling and transcription into a single Capture Meeting Notes button.
  • Automatic Dual Download: Automatically generates and downloads both the AI meeting summary (.md) and raw transcript (.txt) when a call ends or when clicking Stop.
  • Curated Gemini Flash Models: Automatically selects from the latest two stable Gemini Flash models, with support for specifying a custom model ID.
